A Earth Explore — Satellite-Based NDVI Analysis

Earth Explore is a Python-based project for calculating and visualizing the Normalized Difference Vegetation Index (NDVI) using satellite imagery.

Features

- NDVI calculation using Red (B04) and Near-Infrared (B08) bands
- Raster data processing with Rasterio and NumPy
- Interactive data dashboard using Streamlit
- NDVI charts and location-based data exploration

Tech Stack

- Python
- NumPy
- Pandas
- Rasterio
- Streamlit
- Matplotlib

Run Locally

1. Clone or download this repository.

2. Install the required libraries:
   
   "pip install streamlit numpy pandas rasterio matplotlib"

3. Run the dashboard:
   
   "python -m streamlit run app.py"
